## 4. ARTICLE (Copywriter → Editor final)

Markdown body per SKILL.md conventions: H1 → hook → direct answer → H2/H3 sections → scenarios → nuances → common mistakes → next considerations → FAQ (4–8) → **Next:** internal links → (commercial posts) Transparency footnote. When publishing, frontmatter follows SKILL.md; in chat, frontmatter goes on top of the article as a code block.
