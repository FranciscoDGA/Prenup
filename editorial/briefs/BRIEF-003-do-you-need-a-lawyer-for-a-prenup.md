## RELEVANT STATE
Yes: California — a prenup is presumed invalid unless each party had independent counsel or signed a written waiver ≥7 days before signing; waiving spousal support requires independent counsel (Cal. Fam. Code §§ 1612, 1615). UPMAA states consider access to independent representation. State laws otherwise vary.
