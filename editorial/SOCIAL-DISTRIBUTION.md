# Social Distribution (FASE 25–35)

**No accounts are connected to this repo.** This file defines the process + guardrails so distribution can start deliberately, not automatically.

## FASE 25 — Channel fit (US audience) — chosen order
1. **LinkedIn** — Francisco's professional/personal brand; long-form posts adapt well from guides. Low spam risk.
2. **Pinterest** — strong for wedding/finance planning audience; guide hero images already exist (`public/images/guides/*.jpg`) — reuse, no new image system (FASE 30).
3. **Reddit** — highest upside, highest risk (see below).
4. **Facebook** — only value-first participation in relevant groups; no pages automation.
5. **Instagram / X** — later; visual thread / brevity formats don't match this content yet.
System permits choosing channels; nothing requires all of them.

## FASE 26 — Reddit policy (hard rules)
- NEVER: "Read our article!" posts, crosspost spam, drive-by links, astroturfing.
- ALWAYS: **answer the question first**, in the community's own terms; link only when the link is genuinely the most helpful artifact, ideally when asked.
- Respect each community's self-promo rules; disclose affiliation honestly (pastor transparency persona).
- Low volume, high usefulness. Reputation > reach.

## FASE 27 — Content per article (one core idea, adapted)
```
ONE CORE IDEA (from the article's short answer)
  → short post (native phrasing)
  → question post (engagement variant)
  → useful explanation (comment-answer variant)
  → optional article link (only where it helps)
```
Never 20 identical posts. Max ~1–3 posts per article per platform run.

### Core ideas — published articles
- **what-is-a-prenup:** "A prenup is a contract about money — not kids, not love, not 'planning the divorce.'" → link.
- **how-long-does-a-prenup-take:** "6–10 weeks of real work. Start 3–6 months out. California adds a hard 7-day rule most couples never hear about." → link.
- **do-you-need-a-lawyer-for-a-prenup:** "Most states don't force lawyers. Courts still ask who gave you advice." → answer-first in legal/finance threads; link only if it clearly helps.

## FASE 28 — Pinterest
Per promoted article: exact article title (no hype), one useful visual concept (reuse existing hero image), concise description with the real takeaway, canonical URL. No misleading pins.
